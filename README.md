# SPI語句トレ | 公開デモ

SPIの語句・二語の関係の学習に向けて作ったWebアプリの公開用デモです。HTML・CSS・JavaScriptで構築し、カード表示、5・6択クイズ、正誤判定、解説、学習記録、JSON取り込みを実装しています。

## 公開データについて

- 公開リポジトリには独自に作成した少数のサンプル問題のみを収録しています。
- 書籍や有料教材の問題文・解説・選択肢は公開しないでください。
- JSONインポートはローカルのブラウザ内で行い、GitHubや外部サーバーには送信しません。
- 取り込んだ問題と学習履歴は端末の `localStorage` に保存します。端末間同期はありません。

## 機能

- 二語の関係：5択・6択問題、採点、解説、前後移動、正答率集計
- 単語カード：例文と意味の切替、学習済みチェック
- JSON取り込み：問題・単語データの差し替え
- レスポンシブレイアウト：PC・スマートフォン対応
- PWA：対応ブラウザでオフライン閲覧に対応

## GitHub Pages で公開する

1. **新しい** Public リポジトリを作成します（例：`spi-vocab-portfolio`）。元の学習用リポジトリから Fork しないでください。
2. このフォルダーのファイルだけを新しいリポジトリのルートにアップロードします。`index.html` と `app.js` が同じ場所にあることを確認してください。
3. Settings → Pages → Build and deployment → **Deploy from a branch** を選び、`main` / `/(root)` を指定して保存します。
4. 公開後 `https://ユーザー名.github.io/spi-vocab-portfolio/` から動作確認します。

このデモは公開用です。元のリポジトリのGit履歴や問題ファイルはコピーしていません。

## ローカル起動

Pythonがあれば展開したフォルダーで `python -m http.server 8000` を実行し、`http://localhost:8000` にアクセスしてください。ファイルをダブルクリックして開く場合は初期データのfetchやService Workerが動作しません。
